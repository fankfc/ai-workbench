Scope: fixed-source Node SDK host plus installed canonical CJS, one guarded deferred session, no inference. The prior HTTP200 receipt proves current account availability for `account:zai-start-plan` with `GLM-5.3`/`GLM-5.3-Flash`; it does not prove execution identity. Frozen SDK200 evidence stays untouched.

1. **Actual source and account overlay.** Read only the installed public builtin release (`D:/zcode/resources/config/provider/zcode-builtin.json`) through official decoder/config types; no personal/user configuration repository. Compose public ProviderConfigService + AccountProviderService/createAccountProviderConfigSource ports. Official account resolver reads current active family/profile privately through OAuthRepo, and uses the already genuine availability projection with its receipt SHA256, original capture time and explicit short cache bound. Nonmatching family/provider, missing private account identity or expired cache fails closed. Other plan/family availability is unknown; no paid-plan assumptions, manual entitled flags or fabricated provider IDs. SDK resolver derives entitled/current/models and revision. Keep the receipt cache explicitly reused rather than claiming a new fetch. No new balance GET is implicit; if required, report the exact need first.

2. **Anonymous protocol transport and strict metadata.** Outer D011 ProcessManager starts the trusted Node helper in a Windows Job. It may spawn only the fixed Node+CJS app-server command, with anonymous stdin/stdout/stderr pipes and inherited Job; raw frames and any credential material remain in private memory. No NativeRpc inbox, protocol tap, debug/raw logfile or production hardlist change. Use official exported ZCodeProtocolClient/ZCodeStdioTransport ports (node.ts:122–124). Follow official agent synchronization at zcodeAgentService.ts:1511–1544: send provider/updateAccountConfig with real SDK snapshot revision, basedOnZCodeBuiltinRevision, serialized overlay and states; require exact receivedRevision. This is a public protocol request, not private Electron IPC. Reject errors or version mismatch without relaxing schema.

3. **One own metadata session.** After synchronization, send session/create with fixed workspace, mode guarded, persistence deferred, titleGenerationEnabled false, toolAllowlist [], dynamicWorkflowEnabled false, offPeakToolEnabled false, and model {providerId:account:zai-start-plan,modelId:GLM-5.3,options:{reasoningLevel:low}} only if actual account/catalog plus builtin rules admit it. Handle runtime-preferences callback honestly with -32601 (official fallback); all header/permission/browser/unexpected callbacks fail closed in this zero-model slice. Read only that newly created session and close it. Require returned available/current refs exactly match the selection and received revision; catalog echo remains configured identity. Bounds: whole<=60 seconds, private raw frame bytes capped, outer Job cleanup required. Final output only whitelist refs, IDs, fixed codes, booleans/counts and receipt provenance, not snapshot revision strings containing private connection identity or raw account state.

4. **Genuine request-auth and model evidence remain separate.** Official createAccountProviderRequestAuthService.ts:78–90 obtains the current StartPlan JWT through its injected OAuthRepo, and zcodeAgentService.ts:1402–1417 returns headersApplied:true only with actual nonempty requestAuth. It must be wired inside the future private host, with exact session/workspace/provider/model/turn binding; it is never acknowledged by an unsupported client or minted from a boolean. No header callback is expected or accepted as success before model authorization. Public createZCodeAgentService is real, but createSession has a legacy compatibility retry at 3848–3863 which can omit requested fields, including toolAllowlist. This narrow slice uses the exported strict protocol client directly, preserving the public account/config/auth services, rather than exercising that broad compatibility path or unrelated automation/plugin ports.

The production transport's metadata hardlist and frozen source are unchanged. The installed CLI remains the actual runtime. Stock createLocalServices and Electron host/IPC are excluded. Empty toolAllowlist filters root-task builtin and registered MCP tools; it is not an OS sandbox and does not disable bootstrap MCP processes. Storage peer independently traces this and actual response-model fields. A session's current model is not server-origin response.model. runner-debug responseModelId has an AI SDK result.response.modelId source, but its default debug path includes sensitive request material and is forbidden; no public metadata-session response can prove execution model identity. If no safe public response observer survives normalization, root must preserve that precise qualification gap before any dedicated B trial.
