# D018 implementation

History, SSE and outbox dispatch/replay share the same server projection. The projector loads the actual persisted event and task and denies raw model/tool/translation/validation/unknown kinds. Pending, errors, cancellation and clarification use fixed public payloads. A model's visibility flag or publication claim grants no authority.

The trusted native publisher requires an actual current artifact, current A review, hashed evidence and dependency fence. Both staging and publication bind the review to the persisted contract digest, task, attempt, route and revision. The staged review digest prevents post-staging changes to the review or budget from gaining authority. Publication atomically stores PUBLISHED, its state/answer outbox records and a frozen registry tied to the exact answer event. It rereads evidence and bytes before commit. Cancellation, old attempts, stale revisions, changed evidence and missing gates prevent publication. The projector rereads approved bytes instead of temporary model prose. Previously published versions remain available as historical records; unapproved events cannot borrow a later release.

17 projection cases and 13 native publisher cases pass. Evidence-change and six contract/review rebinding counterexamples failed before their fixes; independent probes also confirmed the original five publisher variants now block with zero answers. Public JSON and SSE canary evidence are retained. Positive publication tests use actual local artifacts and a clearly marked fake provider boundary. An A PASS does not turn a B artifact into an A canonical original: required provenance must reference actual A response bytes and a trusted issuer record. Claude publication remains blocked pending complete English input, actual A canonical authorship, Chinese translation and QA. Formal attachments remain blocked pending the bundle publisher; their payload strings cannot activate release.
