# 范围 v2：个人直接使用（不发行）

生效时间：2026-10-16（Asia/Shanghai）。授权依据：用户直接指令"我不需要发行只是直接用所以不需要证书"。决策条目：[DEC-010](decision-log.md)。v1 原文（[scope-v1.md](scope-v1.md)）与其来源快照（[requirements-v1.json](requirements-v1.json)）保留不动；本文件只登记差异，不重复 v1 全文。

## 与 v1 的差异

| 维度 | v1（工业化交付） | v2（个人直接使用） |
| --- | --- | --- |
| 交付形态 | 签名安装包 + 签名更新 + 发布清单 | 未签名内部包（阶段三已交付）即最终形态 |
| 代码签名 | D052/D053 必需 | 取消；无分发即无签名威胁模型 |
| 受控试用/发布评审/交接 | D055–D057、D060 | 取消；用户本人即唯一使用者与验收人 |
| 四类真实任务验证 | 发行前正式演练（D055） | 改义为本人日常使用中的真实验证，仍以真实模型接入为前提 |
| 质量/token 声明 | 发布结论的证据基础 | 保留开放（D043/D044），仅不再阻塞发布 |
| 本地能力 | 安装、迁移、备份、恢复、更新回滚 | 全部保留有效，签名验证部分除外 |

## 取消的任务卡

D052（Windows 安装、打包与代码签名）、D053（签名更新与可恢复回滚）、D056（受控试用与用户反馈闭环）、D057（正式发布评审与缺陷关闭）、D060（终验交接与长期维护）——以上仅取消其签名/发行/对外交接专属范围；各卡已交付的本地能力（未签名包、更新协调器、备份恢复、运维控制器、运行手册）保持有效并继续由 D058/D059 维护。

## 直接使用的前提（开放项）

1. D004：Claude Code 登录（用户本人操作），随后完成真实适配验证与生产连接注册。
2. D005：按 [复检报告](../acceptance/D004-D005-recheck-20261016.md) 的三路线择一（CLI 升级 / 厂商方案 / 独立 API Key）。
3. 两者就绪后经 D020/D024/D040 打通真实垂直链路，即可日常使用；`npm run desktop:demo` 可先行体验界面与本地调度（明确标记模拟，不计真实验收）。

## 不变项

质量零折扣（DEC-002）、A 完整英文定稿（DEC-003）、语言与配对规则、用量真实口径、恢复与取消真实性等全部硬约束不变。本变更只移除发行与签名义务，不降低任何已冻结的产品行为标准。
