# 提议的维护节奏

本文件是人工执行计划；没有创建自动化、提醒或监控任务。指定维护人与用户验收代表后记录实际日期、机器、版本、命令、结果和哈希。

| 频率/触发 | 动作 | 证据与未完成规则 |
| --- | --- | --- |
| 每日工作时 | 查看健康、blocked/恢复/译文拒绝、真实用量完整率与备份完整性 | 未知保留 unknown；备份失败停止清理 |
| 每周 | 手动运维 review、日志清理 preview、未关闭事故和用户反馈 | 仅确认既有 preview 后清理；记录责任人 |
| 每月 | 新隔离目录实际恢复 | 原数据保留；schema、所有文件哈希和重启复验 |
| 每季度 | 锁依赖、SBOM、许可、安全回归与可信签名链 review | 新候选重新绑定；不得延用旧报告 |
| provider/模型版本变化 | 冻结受影响资格，独立新样本质量/token 复验 | route_for 与 publication freeze 重启仍有效 |
| 术语/策略变化 | 双语审批、不可变新版本、失效实际缓存并复验 | 原交付物不覆盖；保持变更记录 |

首次正式安装、真实模型测试、受控试用、生产签名与终验日期均未确定，不以日期推导完成。
