# A 独立基准与协作评估协议草案

版本 1.0-draft。当前没有真实试点、正式样本、实际模型资格或评审签名；本文件没有冻结资格，不支持质量或节省宣传。

十二层为编程、论文、文档、综合 × 简单、中等、困难。每层先取得 5 个独立试点，共 60 个，估计变异及开展功效分析；试点与所有调参任务不得进入正式 holdout。正式样本数、A token 上限、一次分析时间及实际配置尚未登记，在获得这些材料后创建新版本及不可覆盖的冻结记录。

六维量表为正确性、完整性、推理、证据、一致性、可用性，各在 [0,1] 量表评分。否定、条件、数字、来源、版本配对、跨会话读写、凭证泄漏或错误发布属于关键缺陷。任何新增关键缺陷拒绝资格。失败交付六维均记零，全部尝试、返修、翻译、取消、A 审查、A 接管和 A 完整英文定稿用量进入成本；未知和估计量不能充当真实节省证据。

Claude 两臂使用双语领域评审核对的同义英文需求和相同澄清结果，交付仍对照原中文要求。资料、工具、格式、预算、完整 A 英文原件要求相同。随机执行顺序、匿名臂标签；至少两位独立领域评审盲评，分歧由第三人裁决。随机种子 4317。功效分析、样本范围、材料/工具哈希、审查人与签字在看正式结果前冻结。

提议统计法为独立配对样本的单侧 Hoeffding 下界，Bonferroni 在全部 12 × (6 + 1) = 84 个比较上控制整体 α=0.05。质量差范围 [-1,1]；A token 差范围为 [-M,M]，M 是各层事先注册的每任务 A 总 token 上限，包括失败/返修。下界为样本均值减去范围宽度 × sqrt(log(84/0.05)/(2n))。每个必要质量维度下界必须 ≥0，A token 差下界必须严格 >0。该界保守，样本量须经独立试点和功效分析确定；不能为得到资格事后切换统计法、放宽范围或删慢/失败样本。统计置信度并不允许质量折扣。

资格只适用于实际 A/B 版本、领域、难度、任务配置、翻译策略、术语版本、调度策略和协议哈希对应的范围。模型或任一策略变化使资格失效。配置未测、量表不完整、样本不足、人评未签或计量不完整时采用 A 主导路由，整体优化目标保持未完成。

正式执行后追加原始哈希样本、真实身份/用量回执与盲评裁决，不覆盖协议。用于修复的 holdout 样本退出未见集，并由独立保管者补充新样本。功能发布资格与优化目标资格独立评审；任何本地 fixture 只能证明评估器行为。
